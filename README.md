# BYBLACK Office

Android icin Turkce ve Ingilizce Office uygulamasi.

## V5.3 Beta

- Excel dosyalarini acma ve hucre duzenleme
- PDF sayfalarini gercek sayfa gorunumuyle acma
- PDF uzerine yazi ekleme
- PDF'yi yeni dosya olarak kaydetme
- Turkce / English arayuz
- Ozel BYBLACK uygulama simgesi

## Indirme

APK dosyasi GitHub Releases bolumundedir.

## Beta uyarisi

PDF kaydetme islemi sayfalari goruntu olarak yeniden
olusturabilir. Secilebilir metinler, formlar, baglantilar
ve dijital imzalar korunmayabilir.

Excel kaydetme ve PDF yeniden acma islemleri farkli
dosyalarla test edilmelidir.

Word ve PowerPoint icin tam duzenleme destegi
henuz vaat edilmemektedir.

## Derleme

Java kaynaklari app/src klasorundedir.
Termux, Android SDK, Apache POI ve PDFBox kullanilir.
Tekrarlanabilir derleme betigi daha sonra eklenecektir.

## Lisans

Proje ve ucuncu taraf bagimliliklarinin lisans
incelemesi devam etmektedir. Henuz acik kaynak
kullanim lisansi verilmemistir.
